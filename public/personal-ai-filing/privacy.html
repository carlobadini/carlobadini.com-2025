Privacy policy

Last updated: 2 November 2026

personal-ai-filing is a private tool used only by its owner, Carlo Badini, to organize documents from the owner's own accounts. It has no other users and is not offered to the public. This policy explains what Google user data the tool accesses and what it does with it.

Data accessed

  • Gmail (scope gmail.readonly): message headers (sender, recipients, subject, date), a short excerpt of the message body for context, and attachments, for messages that have attachments or are documents themselves (such as receipts and booking confirmations).
  • Google Drive (scope drive.readonly): file metadata and file contents, only in folders and shared drives the owner has selected.

Access is read-only. The tool never sends email, and never modifies, moves, renames, deletes or re-shares any message or file.

How the data is used

The data is used only to provide the tool's single purpose: finding, classifying, archiving and searching the owner's important documents. Extracted text, metadata and copies of important attachments are stored on the owner's own computer. Google Drive files are indexed, not copied.

Sharing

To classify a document, the tool may send its extracted text to Anthropic's Claude API, only for accounts the owner has authorized for this. Anthropic does not use API data to train its models. No data is sold, used for advertising, or shared with anyone else.

Storage, security and deletion

Data stays on the owner's own devices (and the owner's own backups). OAuth tokens are stored in the operating system's secure keychain. Access can be revoked at any time at myaccount.google.com/permissions; archived data can be deleted by deleting the tool's data folder.

Limited Use

personal-ai-filing's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
